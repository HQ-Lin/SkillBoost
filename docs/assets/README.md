# Paper figures

These SVG figures were converted from the vector PDFs in the official LaTeX source bundle for [arXiv:2607.26643](https://arxiv.org/abs/2607.26643), allowing them to render directly in the GitHub README:

- [`skill-overfitting.svg`](skill-overfitting.svg) from Figure 1 (`Fig/Fig1.pdf`);
- [`skillboost-framework.svg`](skillboost-framework.svg) from Figure 2 (`Fig/Fig2.pdf`);
- [`best-of-n.svg`](best-of-n.svg) from the Best-of-N cost-gain analysis (`Fig/figure_bestofn_combined.pdf`).

The conversion preserves vector paths and the original PDF crop regions. Raster elements already embedded in the source PDFs remain embedded rather than being redrawn. The figures are included for scholarly description of the accompanying implementation. The paper and its source are distributed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
