# Paper figures

The PNG figures in this directory were rendered from the official LaTeX source bundle for [arXiv:2607.26643](https://arxiv.org/abs/2607.26643):

- `skill-overfitting.png` from Figure 1;
- `skillboost-framework.png` from Figure 2;
- `best-of-n.png` from the Best-of-N cost-gain analysis.

The figures are included for scholarly description of the accompanying implementation. The paper and its source are distributed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). No semantic content was redrawn; the PDF figures were rasterized and whitespace-cropped for README display.
