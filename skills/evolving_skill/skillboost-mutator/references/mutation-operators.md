# Mutation operators

## ADD

Use when no reusable instruction covers the causal error. State positive applicability, exclusions, and priority. Prefer one mounted reference over expanding the entrypoint with conditional detail.

## REFINE

Use when existing wording is ambiguous or too broad. Edit the authoritative location instead of appending a contradictory exception elsewhere.

## REORDER

Use when the right checks exist but execution order makes them ineffective. State the dependency or invariant that requires the order.

## PRUNE

Use when guidance is contradicted, duplicated, unreachable, or creates demonstrated interference. Preserve information needed by unaffected task classes.

## DECOMPOSE

Use when a recurring subtask exceeds what declarative guidance can reliably control. Define a narrow sub-skill or deterministic helper with an explicit interface. Decomposition is not an excuse to broaden task scope or acquire new permissions.

## Interference review

For every mutation, search the entire skill for overlapping definitions, opposite priorities, stale examples, and unreachable references. A local diff can create a global contradiction.
